Its pinned source bytes are SHA-256 `b198d3e8d2070f0fd7e81c450576c34c3eba59b23bc0e0dbec98a10917a0e33b`; Git and filesystem hashes agree at `fb0fe823539f6d04850f6e34748c01f01f212e1f`. The unchanged original passed all five tests with Node 26.13.0 and Vitest 4.1.12.

`TestTaskSchedulerV170CascadeReasonUsesNearestCancellingOwner` failed on the unchanged native base because the scheduler rewrote the middle restart reason from its explicit ancestor before marking the leaf. The fix preserves bounded one-write reconciliation: it first marks unmarked descendants, so their first write observes the nearest cancelled owner, then applies explicit-intent supersession to restart-only marks on later passes. `TestTask120ExplicitAbortSupersedesRestartBlockedChild` remains green, proving the existing eventual supersession policy.
