- `scripts/generate-model-schemas.ts` checks the actual f9 source and pi-schema1.5.0 dependency, replacing the obsolete TypeBox-based input contract. It checks three source hashes, including `schema-builders.ts`, and the installed dependency version. ## Verification

All commands use Go1.27.3, `CGO_ENABLED=0`, `GOMAXPROCS=4`, with `scripts/project-env.sh` and project-owned scratch.

Before changes, the default-identity oracle failed both version and User-Agent assertions (.005s); the schema generator rejected the actual1.5.0 input, and the catalogue generator rejected its manifest. Subsequent full-record comparisons separately exposed each omission above. Initial comparator development used the provider map key as the ID and had not normalised the typed compat union; those were harness errors, not production failures.

Final results:

- **1712/1712 full public records match** the official archive:1592 chat,64 image,56 classifier. All three source regeneration comparators pass.
- Five selected functions repeated three times/shuffle42:15 top-level passes, no failures/skips; public tests .033s and generator test .004s. These include exact default identity, three metadata witnesses/ownership, retained HTTP identity controls, shared schema controls and the existing reasoning-emitter regression at its original source pin.

Two unchanged native exact-precision rejection controls differ after JavaScript input rounding (cost underflow and a decimal beyond the safe-integer bound); they confer no source-parity credit. The renamed test states this explicitly. Complete compiler/error/precision convergence remains open.
- Restoring each metadata omission independently causes a full-record rejection. The first overlay attempt addressed only the physical path and survived because Go used the logical alias; no rejection credit is taken. Corrected logical+physical overlays reject effort/free/output faults.
- Wrong package version and changed builder-source probes are rejected. The existing chat/image/classifier non-ID metadata corruption self-test passes after its diagnostic pin was revised.
