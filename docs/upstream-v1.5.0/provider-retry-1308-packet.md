# Zhipu 1308 retry classification

Pinned `packages/ai/src/utils/retry.ts:32–34,116–124` excludes Zhipu/Z.ai error code `1308` from retry before matching HTTP 429 or transient guidance. Its case-insensitive pattern matches a quoted `code` key, optional whitespace and optional quote before `1308`, but not a following digit. No corresponding `1308` test was found in the pinned `packages/ai/test` search, so the two Go regressions are source-derived rather than translated upstream tests.

At parent `9a64f99`, `TestMainRetryZhipu1308ProviderLimitPrecedesTransientGuidance` failed three cases: numeric, quoted and uppercase-key 1308 combined with 429/transient text were incorrectly retryable. The implementation now adds the source exclusion to `nonRetryableProviderLimitErrorPattern`. RE2 lacks lookahead, so the match consumes a following non-digit or end of string; only match existence is used. Longer 13080/13081 codes, `error_code`, unrelated plain text, non-error stop reasons and normal retry guidance remain separate controls.
