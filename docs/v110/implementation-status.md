## Durable scope and latest verification -- 8 October

Rui removed the legacy durable compatibility requirement. The active target is the official 1.1.0 durable API and behaviour; old native interfaces and journals need not constrain implementation. Correctness, cancellation, detached ownership and security checks still apply. AI compatibility and published 1.0.4 refs/assets are unchanged.

Ordered conversation/task/submission pages and fork-aware ascending/descending entry scans are implemented in `durable/scan.go` and `durable/history.go`. The 1.1.0 scans are required by `Storage`, exposed through Session and conversation history, with no old-backend fallback. Direct storage entry scans default descending; conversation history defaults ascending and continuations preserve either direction. Continuations persist order and reject direction/filter drift; transaction scans include staged writes. Optional task start/end timestamps use the Session/Harness clock, preserve the first staged/committed values across waits and recovery, and detach timestamp pointers at read/copy boundaries.

## Final candidate implementation and local gates

* Response timing is producer-owned in every native provider. Progress snapshots detach duration pointers, explicit zero is retained, and terminal ownership stays unchanged. Redundant OpenAI snapshots were removed after CPU/allocation analysis.
* Radius replaces its provider baseline with a known account catalog, including empty lists. Faux compares prompt parts/prefixes with UTF-16 accounting and isolated session caches. Native lazy setup is compiled; no JS module-loader promise exists.
* Anthropic supports manual redirect input after both callback listeners fail, validates state/redirect authority and joins the cancellation-aware prompt. Codex browser login supports originator, PKCE, callback/manual selection and browser-client refresh, preserving native device-flow default.
* Durable contexts support visible as-of cutoffs, leading baseline system messages, incremental contribution/open-suffix derivation, edit/head/fork/out-of-order invalidation and idle expiry. Default retention is600000ms; explicit zero drops idle caches. Reads remain detached and caches close with the Session.
* Harness Catalog shares credential-scoped discovery/refresh with tasks, tools and hooks. Invocation-bound `ModelAccess.Complete` uses the same process-local RequestOptions boundary and rejects ended authority.
* SQLite required scans share the native validated core; ordered cursor/reopen tests pass. Cloudflare's JS Durable Object SqlStorage adapter is platform-specific N/A, with no deployment claim.
